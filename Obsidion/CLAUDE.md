# 이 보관함(Vault) 사용 규칙

## 문서 작성
- 모든 노트는 Markdown(.md)으로 작성한다.
- 관련 있는 다른 노트는 `[[노트 이름]]` 형식의 위키링크로 연결한다. 링크 대상이 아직 없는 노트여도 괜찮다 — 나중에 작성할 노트의 표시로 남겨둔다.
- 새 노트를 쓰기 전에 관련 노트가 이미 있는지 먼저 찾아본다(폴더 탐색·링크 추적·검색). 중복 생성보다 기존 노트 보강을 우선한다.

## 건드리지 말 것
- `.obsidian/` 폴더(설정, 워크스페이스, 플러그인 구성)는 사용자가 Obsidian 앱에서 직접 관리한다. 자동으로 수정·삭제하지 않는다.
- 첨부파일(이미지, PDF 등)은 삭제하거나 이동하지 않는다. 노트에서 참조가 끊기지 않도록 주의한다.
